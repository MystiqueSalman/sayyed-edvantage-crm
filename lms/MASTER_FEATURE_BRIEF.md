## PRODUCT VISION

## 29. RECOMMENDED PLATFORM ARCHITECTURE
- Frontend: Next.js + TypeScript
- Backend: Python + FastAPI
- Database: PostgreSQL
- Cache/Queues: Redis
- Background Jobs: Celery or equivalent
- Storage: S3-compatible object storage
- Search: OpenSearch/Elasticsearch where required
- AI Layer: LLM + RAG + vector search + agent orchestration
- Deployment: Docker + cloud infrastructure
- Mobile: PWA initially, then native/cross-platform applications
- Architecture: API-first, modular, secure and multi-tenant ready

## 31. PLATFORM PRINCIPLE
The LMS should be designed as an AI-native education operating system rather than a simple video-course website. Every major module should expose secure APIs and events so that the Student App, AI Agents, CRM, WhatsApp, payments, analytics and future services operate from the same source of truth.
